# Papa Meals Planner — Home Care Guide

A single-page web app for the family caregiver: 24-hour care timetable, tube-feeding plan, care procedures (trach, suction, flap, exercises) and emergency signs.

- Languages: Burmese (မြန်မာ), English, Thai (ไทย)
- Large text with A+/A− size buttons, bottom menu, "Now" highlight on the timetable
- Done-ticks and phone numbers are saved only in the browser (localStorage)

## Deploy on Netlify

No build step. In Netlify choose **Add new site → Import from Git**, pick this repo, leave the build command empty and set the publish directory to `.` (already set in `netlify.toml`).

> General guidance only — always follow the patient's surgical, nutrition and diabetes team.
